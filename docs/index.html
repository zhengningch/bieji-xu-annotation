四、同一作者在兩種文體間的形式分化

計算：先合併同一作者各文體的所有句子，分別計算駢句率。方向差＝墓誌銘駢率－別集序駢率；絕對差＝｜方向差｜，表示兩種文體形式分化的強弱。這能呈現文體選擇差異，但不能單獨證明作者的主觀意圖。
